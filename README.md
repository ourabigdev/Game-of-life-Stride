# Game of Life – Stride Engine

A simple implementation of Conway’s Game of Life built using the Stride game engine.
This project focuses on custom 2D scene rendering entirely through code, without relying on built-in editors.

It also leverages utilities from the Stride Community Toolkit to simplify development and extend functionality.

## Features

* Pure code-driven 2D rendering
* Conway’s Game of Life simulation
* Lightweight and easy to understand structure

## Purpose

This project is mainly for learning and experimenting with Stride’s rendering pipeline and ECS system while building a classic cellular automaton.
